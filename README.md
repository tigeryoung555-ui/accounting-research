# 会计学研究与探索

> 一个关于会计学的开放式学习与研究项目，涵盖会计历史、中外比较、现代管理会计以及 AI 与会计的融合。

## 📚 项目简介

本项目旨在系统梳理会计学的发展脉络与前沿应用，通过文献整理、案例分析和跨学科比较，为会计学习者、研究者和从业者提供一份结构化的参考资料。

## 📂 内容板块

### 1. 会计历史研究
追溯会计的起源与演进，从复式记账法的诞生到现代会计体系的建立。
- 古代会计（结绳记事、官厅会计）
- 近代会计（帕乔利与复式记账法）
- 现代会计（工业革命与会计准则）
- 中国会计发展史

### 2. 中外会计比较
对比不同国家和地区的会计体系与准则差异。
- 中国企业会计准则 vs 国际财务报告准则（IFRS）
- 美国 GAAP 与中国准则的差异
- 主要国家会计监管体制比较
- 会计准则国际趋同进程

### 3. 现代管理会计
探讨管理会计在企业决策中的应用与发展。
- 成本管理与控制
- 预算管理与绩效评价
- 战略管理会计
- 作业成本法（ABC）
- 平衡计分卡（BSC）

### 4. AI 与会计结合
聚焦人工智能技术在会计领域的应用与变革。
- 财务机器人（RPA）与自动化
- 机器学习在财务预测中的应用
- 智能审计与风险识别
- 大语言模型在会计工作中的实践
- AI 对会计职业的影响与转型

## 🛠 技术栈

本项目采用**零代码门槛**的方案：

| 技术 | 用途 | 学习难度 |
|---|---|---|
| Markdown | 编写所有文章内容 | ⭐ 非常简单 |
| GitHub | 版本管理与协作 | ⭐⭐ 简单 |
| GitHub Pages | 免费托管网站 | ⭐⭐ 简单 |

> 不需要安装任何编程环境，只需要一个 GitHub 账号和文本编辑器。

## 🚀 快速开始

### 方式一：直接在 GitHub 上编辑（最简单）

1. 登录 GitHub，进入本仓库
2. 点击 `docs/` 文件夹，选择对应主题
3. 点击右上角铅笔图标 ✏️ 直接编辑
4. 编辑完成后点击 "Commit changes" 保存

### 方式二：本地编辑（适合大量写作）

1. **安装 Git**（[下载地址](https://git-scm.com/downloads)）
2. **克隆仓库到本地**：
   ```bash
   git clone https://github.com/你的用户名/accounting-research.git
   cd accounting-research
   ```
3. 用任意文本编辑器（推荐 [VS Code](https://code.visualstudio.com/)）打开文件夹
4. 在 `docs/` 对应目录下创建或编辑 `.md` 文件
5. 提交并推送：
   ```bash
   git add .
   git commit -m "添加新文章"
   git push
   ```

### 方式三：预览效果

Markdown 文件可以直接在 GitHub 上渲染查看，也可以用 [Typora](https://typora.io/) 等编辑器实时预览。

## ✍️ 如何贡献内容

1. 在对应主题文件夹下创建新的 `.md` 文件
2. 文件名使用中文或英文，例如：`复式记账法的起源.md`
3. 文章开头建议包含：
   ```markdown
   # 文章标题
   > 简短摘要
   
   ## 正文内容...
   ```
4. 提交时写明修改内容，例如 "添加管理会计-作业成本法"
